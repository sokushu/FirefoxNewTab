# FirefoxNewTab

ウェブサイトのショートカット、グループ、背景のカスタマイズ、任意で表示できる時計を備えた、軽量な Firefox の新しいタブ用拡張機能です。Manifest V3 と標準の HTML、CSS、JavaScript で実装されており、依存パッケージのインストールやビルドをせずにソースファイルから直接読み込めます。

## 機能

- 4 種類のアイコンサイズに対応したグリッドでショートカットをドラッグして配置し、空きマスも含めて保存します。
- 折りたたみ可能なサイドバーでグループを管理し、グループ間でサイトをドラッグして移動できます。
- 独自のアイコンをアップロードするか、必要なときにサイトから直接取得できます。
- 同梱の壁紙 7 枚、ローカル画像、48 色の背景色から選べます。
- ダーク、ライト、システム設定に合わせるテーマを選択でき、現地時刻と日付も表示できます。
- Firefox の表示言語に自動で合わせ、OS の視差効果やアニメーションを減らす設定にも対応します。

## Firefox に読み込む

サイトのアイコン取得には [`optional_host_permissions`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_host_permissions) を使用するため、この機能には Firefox 128 以降が必要です。

1. このリポジトリをダウンロードまたはクローンし、ファイル構成を維持します。
2. Firefox で `about:debugging#/runtime/this-firefox` を開きます。
3. **一時的なアドオンを読み込む…** をクリックし、プロジェクトのルートにある `manifest.json` を選択します。
4. 確認が表示された場合は、新しいタブのページを拡張機能で置き換えることを許可します。
5. 新しいタブを開きます。背景の空いている場所を右クリックして最初のサイトを追加するか、右下の歯車から設定を開きます。

一時的なインストールは Firefox を再起動すると解除されるため、再度読み込んでください。詳しくは [Mozilla の一時インストールガイド](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)を参照してください。

## ウェブサイトのショートカット

### サイトの追加と管理

初回はサイト一覧が空です。背景の空いている場所を右クリックすると、次の操作が表示されます。

| 操作 | 動作 |
| --- | --- |
| アイコンを追加 | 現在のグループにサイトを追加します。 |
| 壁紙を変更 | 設定の同梱壁紙の項目を開きます。 |
| 設定 | 設定パネルを開きます。 |

名前は 50 文字以内、アドレスは HTTP または HTTPS を指定します。スキームを省略すると `https://` が自動で補われます。ショートカットをクリックすると、現在のタブでサイトが開きます。

ショートカットを右クリックするか、右上の三点ボタンを使うと、開く、編集、サイズ変更、削除の操作ができます。三点ボタンはマウスを重ねたときやキーボードでフォーカスしたときに表示され、タッチ端末では常に表示されます。削除には確認が必要です。編集をキャンセルすると未保存の変更は破棄されます。

### アイコンサイズとグリッドの容量

各グループのデスクトップ用論理グリッドは **10 列 × 6 行**で、合計 **60 マス**です。

| サイズ | 列 × 行 | 使用マス数 |
| --- | --- | --- |
| 標準 | 1 × 1 | 1 |
| 横長のアイコン | 2 × 1 | 2 |
| 縦長のアイコン | 1 × 2 | 2 |
| 大きいアイコン | 2 × 2 | 4 |

標準サイズなら 1 グループに最大 60 個のショートカットを配置できます。大きなアイコンには、その形に合う連続した空きマスが必要です。グループが満杯になると追加が無効になり、追加、グループ間の移動、サイズ変更のたびに空き容量を確認します。サイズはサイトごとに保存されます。

ショートカットを空きマスや別のショートカットの上にドラッグすると、周囲の項目を動かして再配置できます。位置と空きマスは保存されます。**Esc** を押すかドラッグをキャンセルすると元の配置に戻ります。スクロール領域の端にドラッグすると、さらに先のマスへ移動できます。

グリッドはサイドバーの右側領域の左上に固定され、必要な場合のみスクロールします。狭いウィンドウでは列数を減らし、列数ごとに別の配置を保存します。狭い画面でドラッグしてもデスクトップの配置は上書きされず、ウィンドウのサイズ変更だけでは新しい位置を保存しません。1 列表示では横方向の幅を一時的に縮め、十分な幅があれば元に戻します。

### グループ

サイドバーには最初に **よく使う** グループがあります。**グループを追加** から新しいグループを作成できます。名前は 20 文字以内です。グループ設定では名前を変更し、文字、絵文字、ローカル画像をアイコンに設定できます。

サイトをグループにドラッグすると移動できます。サイドバーを折りたたんでいる場合も、グループのアイコンにドロップできます。移動先に十分な空きがない場合は元の位置に残ります。

サイドバー上部の矢印で折りたたみと展開を切り替えます。現在のグループと折りたたみ状態は保存されます。最初のグループを含め、どのグループも名前の変更や削除が可能ですが、少なくとも 1 つは残す必要があります。グループを削除すると、中のサイトとアイコンは残りの先頭グループに移動します。

グループ切り替えでは、サイドバーの並び順に応じて上下にスライドします。アイコンのサイズ変更やサイドバーの開閉も滑らかに動きます。これらの効果は OS のアニメーションを減らす設定に従います。

### アイコンのカスタマイズと取得

- サイトとグループのアイコンには、**2 MiB** 以下の PNG、JPEG、WebP、GIF、AVIF、ICO をアップロードできます。
- サイトに独自のアイコンがない場合は名前の最初の文字を表示します。**既定のアイコンを使用** でこの表示に戻せます。
- アイコンは縦横比を維持し、拡大せず、長辺を最大 **512 px** に縮小します。約 **0.8** の品質で WebP に圧縮し、必要に応じてさらに縮小して保存データを **128 KiB** 以内に収めます。
- 保存済みの PNG アイコンも引き続き使えます。旧版で 128 px に圧縮されたアイコンを鮮明にするには、元画像をアップロードするか、再取得してください。

サイトのアドレスを入力して **アイコンを取得** をクリックすると、必要に応じて Firefox がそのサイトへのアクセス許可を求めます。拡張機能はサイトで指定されたアイコンと `/favicon.ico` を試し、取得した画像をローカルのプレビューに変換します。**保存** をクリックすると確定します。取得に失敗した場合や許可しなかった場合も現在のアイコンは保持され、ローカル画像のアップロードを利用できます。第三者のアイコンサービスは使用しません。

## 外観と背景

右下の歯車をクリックすると設定パネルが開きます。閉じるボタン、パネルの外側のクリック、または **Esc** で閉じられます。

| 設定 | 選択肢と動作 |
| --- | --- |
| テーマ | **ダーク**、**ライト**、**システム設定に合わせる**。既定ではシステム設定に従います。 |
| 時計を表示 | 既定ではオフ。24 時間制の `HH:mm:ss` と地域の形式に合わせた日付を毎秒更新します。 |
| 同梱の壁紙 | 7 枚を 2 列で表示。サムネイルをクリックすると適用して保存します。 |
| ローカルの背景画像 | **10 MiB** 以下の PNG、JPEG、WebP、GIF、AVIF。選択後に適用して保存します。 |
| 背景色 | 48 色。色見本をクリックすると適用して保存します。 |
| 既定の背景 | 白（`#ffffff`）。初回や既定に戻したときに使います。 |

テーマは操作部品、メニュー、ダイアログの配色を変更し、選択した壁紙や背景色は維持します。明るい単色背景ではサイト名と時計を濃い文字で表示します。テーマ、時計の表示、サイドバーの折りたたみ設定は、同じ拡張機能で開いている他の新しいタブにも同期されます。

## 表示言語

[`browser.i18n.getUILanguage()`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/i18n/getUILanguage) を使い、Firefox の表示言語に自動で合わせます。拡張機能内に個別の言語選択はありません。

簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語に対応し、ポルトガル語にはブラジル版とポルトガル版があります。地域に対応する翻訳または共通の翻訳を使い、未対応の言語では簡体字中国語に切り替わります。Firefox の表示言語を変更した後は、新しいタブを開き直してください。

メニュー、設定、ダイアログ、メッセージ、アクセシビリティ用ラベル、色名、拡張機能名、日付、既定のグループ名を翻訳しています。ユーザーが入力したサイト名、URL、グループ名はそのまま保持します。時計は常にローカルのタイムゾーンを使用します。

## ローカルデータと権限

| 保存先 | 内容 |
| --- | --- |
| `localStorage` | サイト、アイコン、グリッド位置、グループ、現在のグループ、サイドバーの状態、テーマ、時計の表示設定。 |
| `IndexedDB` | 背景の選択とローカルの背景画像。 |

アップロードした画像はブラウザー内に保存されます。ショートカットや背景の管理には追加の権限は不要です。サイトへのアクセスは **アイコンを取得** をクリックしたときだけ要求し、拒否してもローカル画像はアップロードできます。背景に外部の画像サービスは使いません。ローカルストレージが利用できない場合、管理操作時にエラーを表示します。

### 旧データとの互換性

- 旧版の同梱ショートカットはプリセットの識別情報で削除し、ユーザーが追加したサイトと独自のアイコンは保持します。
- 旧版のフォルダー機能は廃止しました。フォルダー内のサイトは、名前、URL、アイコン、サイズを保持して所属グループのメイングリッドへ移動します。
- 旧データがグリッド容量を超える場合、余ったサイトは **その他のウェブサイト** 一覧から開く、編集、削除ができます。空きができるとグリッドに戻ります。

### 編集と再読み込み

依存パッケージのインストールやビルドコマンドは不要です。ソースを編集した後は、`about:debugging#/runtime/this-firefox` で拡張機能の **再読み込み** をクリックし、古い新しいタブのページを閉じてから、新しいタブを開きます。

`newtab.html` 内のローカル CSS と JavaScript の参照には共通の `?v=...` リソースバージョンを付けています。これらを変更するときはまとめて更新してください。スクリプトの依存順序を守り、`i18n.js` を最初に、共通ユーティリティを利用側より先に、グループ、グリッド、メニュー、切り替え、データ移行の各モジュールを `shortcuts.js` より先に読み込みます。各モジュールは独立したスコープに内部状態を持ち、明示的なインターフェースやイベントを通じて連携します。アイコン処理と容量規則の実装はそれぞれ一か所にまとめ、壁紙選択のスタイルは設定パネル内に限定します。

### 翻訳の更新

`_locales/*/messages.json` では同じメッセージキーを使用します。名前付きの値は `newTabI18n.t(key, { name, count })` で挿入し、静的な内容には `data-i18n`、`data-i18n-title`、`data-i18n-aria-label`、`data-i18n-placeholder` を使います。テンプレート内のメニューも翻訳し、対応する地域別カタログをまとめて更新してください。8 言語の README も同じ内容に保ちます。[Mozilla の国際化ガイド](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Internationalization)も参照してください。
