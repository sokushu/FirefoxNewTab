# FirefoxNewTab

웹사이트 바로가기, 그룹, 사용자 지정 배경과 선택적으로 표시할 수 있는 시계를 제공하는 가벼운 Firefox 새 탭 확장 기능입니다. Manifest V3와 기본 HTML, CSS, JavaScript로 만들어져 의존성 설치나 빌드 없이 소스 파일에서 바로 실행할 수 있습니다.

## 기능

- 네 가지 아이콘 크기를 지원하는 그리드에서 바로가기를 드래그해 배치하고 빈칸까지 저장합니다.
- 접을 수 있는 그룹 사이드바로 사이트를 관리하고 그룹 사이로 바로가기를 옮깁니다.
- 사용자 지정 아이콘을 업로드하거나 필요할 때 웹사이트에서 직접 가져옵니다.
- 기본 배경화면 7개, 로컬 이미지 또는 배경색 48개 중에서 선택합니다.
- 어두운 테마, 밝은 테마 또는 시스템 설정을 사용하고 현지 시간과 날짜를 표시할 수 있습니다.
- Firefox 표시 언어를 자동으로 따르며 시스템의 동작 줄이기 설정을 존중합니다.

## Firefox에서 불러오기

웹사이트 아이콘 가져오기는 [`optional_host_permissions`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_host_permissions)를 사용하므로 이 기능에는 Firefox 128 이상이 필요합니다.

1. 이 저장소를 다운로드하거나 복제하고 파일 구조를 유지합니다.
2. Firefox에서 `about:debugging#/runtime/this-firefox`를 엽니다.
3. **임시 부가 기능 로드…** 를 클릭하고 프로젝트 루트의 `manifest.json`을 선택합니다.
4. 안내가 표시되면 확장 기능이 새 탭 페이지를 바꾸도록 허용합니다.
5. 새 탭을 엽니다. 배경의 빈 곳을 마우스 오른쪽 버튼으로 클릭해 첫 사이트를 추가하거나 오른쪽 아래 톱니바퀴로 설정을 엽니다.

임시 설치는 Firefox를 다시 시작하면 해제되므로 이후 다시 불러와야 합니다. [Mozilla 임시 설치 안내](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)를 참고하세요.

## 웹사이트 바로가기

### 사이트 추가와 관리

처음에는 사이트 목록이 비어 있습니다. 배경의 빈 곳을 마우스 오른쪽 버튼으로 클릭하면 다음 작업을 사용할 수 있습니다.

| 작업 | 동작 |
| --- | --- |
| 아이콘 추가 | 현재 그룹에 사이트를 추가합니다. |
| 배경화면 변경 | 설정의 기본 배경화면 영역을 엽니다. |
| 설정 | 설정 패널을 엽니다. |

이름은 최대 50자이며 주소는 HTTP 또는 HTTPS만 지원합니다. 프로토콜을 생략하면 `https://`가 자동으로 붙습니다. 바로가기를 클릭하면 현재 탭에서 사이트가 열립니다.

바로가기를 마우스 오른쪽 버튼으로 클릭하거나 점 세 개 버튼을 누르면 열기, 편집, 크기 변경, 삭제 작업을 사용할 수 있습니다. 버튼은 마우스를 올리거나 키보드 포커스를 두면 나타나고 터치 기기에서는 항상 표시됩니다. 삭제에는 확인이 필요하며 편집을 취소하면 저장하지 않은 변경 사항은 버립니다.

### 아이콘 크기와 그리드 용량

각 그룹의 데스크톱 논리 그리드는 **10열 × 6행**, 총 **60개의 기본 칸**으로 구성됩니다.

| 크기 | 열 × 행 | 사용 칸 수 |
| --- | --- | --- |
| 기본 | 1 × 1 | 1 |
| 가로형 아이콘 | 2 × 1 | 2 |
| 세로형 아이콘 | 1 × 2 | 2 |
| 큰 아이콘 | 2 × 2 | 4 |

한 그룹에는 기본 크기 바로가기를 최대 60개 배치할 수 있습니다. 더 큰 아이콘에는 모양에 맞는 연속된 빈칸이 필요합니다. 그룹이 가득 차면 추가가 비활성화되며 추가, 그룹 간 이동, 크기 변경 시 모두 남은 공간을 확인합니다. 각 사이트의 크기는 개별적으로 저장됩니다.

바로가기를 빈칸이나 다른 바로가기 위로 드래그하면 주변 항목을 이동하며 다시 배치할 수 있습니다. 위치와 빈칸이 저장됩니다. **Esc**를 누르거나 드래그를 취소하면 원래 배치로 돌아갑니다. 스크롤 영역 가장자리로 드래그하면 더 많은 칸에 접근할 수 있습니다.

그리드는 사이드바 오른쪽 영역의 왼쪽 위에 고정되며 필요할 때만 스크롤됩니다. 좁은 창에서는 열 수를 줄이고 열 수마다 별도의 위치를 저장합니다. 좁은 화면에서 드래그해도 데스크톱 위치를 덮어쓰지 않으며 창 크기만 바꾸면 새 위치를 저장하지 않습니다. 한 열 보기에서는 가로 너비를 일시적으로 줄이고 공간이 확보되면 원래 너비로 복원합니다.

### 그룹

사이드바에는 처음에 **즐겨찾기** 그룹이 있습니다. **그룹 추가**로 그룹을 더 만들 수 있으며 이름은 최대 20자입니다. 그룹 설정에서는 이름을 바꾸고 글자, 이모지 또는 로컬 이미지를 아이콘으로 지정할 수 있습니다.

사이트를 그룹 위로 드래그하면 해당 그룹으로 이동합니다. 사이드바가 접혀 있어도 그룹 아이콘에 놓을 수 있습니다. 대상 그룹에 공간이 부족하면 원래 위치를 유지합니다.

사이드바 위쪽 화살표로 사이드바를 접거나 펼칠 수 있습니다. 현재 그룹과 접힘 상태는 저장됩니다. 처음 제공된 그룹을 포함해 모든 그룹의 이름을 바꾸거나 삭제할 수 있지만 최소 한 그룹은 남아 있어야 합니다. 그룹을 삭제하면 그 안의 사이트와 아이콘은 남아 있는 첫 번째 그룹으로 이동합니다.

그룹을 전환할 때는 사이드바 순서에 따라 위아래로 슬라이드합니다. 아이콘 크기 변경과 사이드바 접기·펼치기도 부드럽게 전환됩니다. 이러한 효과는 시스템의 동작 줄이기 설정을 따릅니다.

### 사용자 지정 아이콘과 아이콘 가져오기

- 사이트와 그룹 아이콘으로 **2 MiB** 이하의 PNG, JPEG, WebP, GIF, AVIF 또는 ICO 파일을 업로드할 수 있습니다.
- 사용자 지정 아이콘이 없으면 사이트 이름의 첫 글자를 표시합니다. **기본 아이콘 사용**으로 이 표시를 복원합니다.
- 아이콘은 원본 비율을 유지하고 확대하지 않으며 긴 변을 최대 **512 px**로 줄입니다. 약 **0.8** 품질의 WebP로 압축하고 필요하면 더 줄여 저장 데이터가 **128 KiB** 제한 안에 들어가도록 합니다.
- 이전에 저장한 PNG 아이콘도 지원합니다. 구버전에서 128 px로 압축한 아이콘의 선명도를 높이려면 원본을 다시 업로드하거나 아이콘을 다시 가져오세요.

사이트 주소를 입력한 뒤 **아이콘 가져오기**를 클릭하면 Firefox가 필요에 따라 해당 사이트의 접근 권한을 요청합니다. 확장 기능은 사이트에서 지정한 아이콘과 `/favicon.ico`를 시도한 뒤 결과를 로컬 미리보기로 변환합니다. **저장**을 눌러야 반영됩니다. 가져오기에 실패하거나 권한을 거부해도 기존 아이콘은 유지되며 로컬 이미지를 업로드할 수 있습니다. 타사 아이콘 서비스는 사용하지 않습니다.

## 모양과 배경

오른쪽 아래 톱니바퀴로 설정 패널을 엽니다. 닫기 버튼, 패널 바깥 클릭 또는 **Esc**로 닫을 수 있습니다.

| 설정 | 옵션과 동작 |
| --- | --- |
| 테마 | **어둡게**, **밝게**, **시스템 설정에 따름** 중 선택하며 기본값은 시스템 설정입니다. |
| 시계 표시 | 기본적으로 꺼져 있습니다. 현지 시간을 24시간제 `HH:mm:ss`로 표시하고 날짜를 표시 언어에 맞춰 매초 갱신합니다. |
| 기본 배경화면 | 이미지 7개를 두 열로 표시하며 썸네일을 클릭하면 적용하고 저장합니다. |
| 로컬 배경 이미지 | **10 MiB** 이하의 PNG, JPEG, WebP, GIF 또는 AVIF를 선택하면 적용하고 저장합니다. |
| 배경색 | 48개 색상 중 하나를 클릭하면 적용하고 저장합니다. |
| 기본 배경 | 흰색(`#ffffff`)이며 처음 실행하거나 기본값으로 복원할 때 사용합니다. |

테마는 컨트롤, 메뉴, 대화상자의 색상을 바꾸며 선택한 배경화면이나 배경색은 유지합니다. 밝은 단색 배경에서는 사이트 제목과 시계를 어두운 글자로 표시합니다. 테마, 시계 표시, 사이드바 접힘 설정은 같은 확장 기능으로 열려 있는 다른 새 탭에도 동기화됩니다.

## 인터페이스 언어

인터페이스는 [`browser.i18n.getUILanguage()`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/i18n/getUILanguage)를 통해 Firefox 표시 언어를 자동으로 따릅니다. 별도의 언어 선택기는 없습니다.

중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 스페인어, 프랑스어, 독일어, 포르투갈어를 지원하며 포르투갈어에는 브라질과 포르투갈 버전이 있습니다. 지역별 언어는 해당 번역 또는 공통 번역을 사용하고 지원하지 않는 언어는 중국어 간체로 표시합니다. Firefox 표시 언어를 바꾼 뒤 새 탭을 다시 열면 적용됩니다.

메뉴, 설정, 대화상자, 메시지, 접근성 레이블, 색상 이름, 확장 기능 이름, 날짜와 기본 그룹 이름이 번역됩니다. 사용자가 입력한 사이트 제목, URL과 그룹 이름은 원문을 유지합니다. 시계는 항상 현지 시간대를 사용합니다.

## 로컬 데이터와 권한

| 저장소 | 내용 |
| --- | --- |
| `localStorage` | 사이트, 아이콘, 그리드 위치, 그룹, 현재 그룹, 사이드바 상태, 테마와 시계 표시 설정. |
| `IndexedDB` | 배경 선택과 로컬 배경 이미지. |

업로드한 이미지는 브라우저 안에 저장됩니다. 바로가기와 배경 관리에는 추가 권한이 필요하지 않습니다. **아이콘 가져오기**를 클릭할 때만 사이트 접근 권한을 요청하며 거부해도 로컬 이미지를 업로드할 수 있습니다. 배경에는 외부 이미지 서비스를 사용하지 않습니다. 로컬 저장소를 사용할 수 없으면 관리 작업 시 오류를 표시합니다.

### 이전 데이터와의 호환성

- 구버전의 기본 바로가기는 프리셋 식별 정보를 기준으로 제거하며 사용자가 추가한 사이트와 사용자 지정 아이콘은 유지합니다.
- 이전 폴더 기능은 제거되었습니다. 폴더 안의 사이트는 이름, URL, 아이콘과 크기를 유지한 채 소속 그룹의 기본 그리드로 이동합니다.
- 이전 데이터가 그리드 용량을 초과하면 남는 사이트는 **기타 웹사이트** 목록에서 열거나 편집하거나 삭제할 수 있습니다. 공간이 생기면 그리드로 돌아옵니다.

### 수정과 다시 불러오기

의존성 설치나 빌드 명령이 필요하지 않습니다. 소스를 수정한 뒤 `about:debugging#/runtime/this-firefox`에서 확장 기능의 **새로 고침**을 클릭하고 기존 새 탭 페이지를 닫은 다음 새 탭을 엽니다.

`newtab.html`의 로컬 CSS와 JavaScript 참조는 공통 `?v=...` 리소스 버전을 사용합니다. 해당 리소스를 수정할 때 매개변수를 함께 갱신하세요. 스크립트 의존 순서를 유지해 `i18n.js`를 먼저, 공통 유틸리티를 사용하는 모듈보다 앞에, 그룹·그리드·메뉴·전환·데이터 이전 모듈을 `shortcuts.js`보다 앞에 불러옵니다. 각 모듈은 별도 범위에 내부 상태를 두고 명시적인 인터페이스나 이벤트로 협력합니다. 아이콘 처리와 용량 규칙은 각각 한 곳에서 구현하며 배경화면 선택기 스타일은 설정 패널 안에만 적용합니다.

### 번역 업데이트

`_locales/*/messages.json`에서 같은 메시지 키를 사용합니다. 이름 있는 값은 `newTabI18n.t(key, { name, count })`로 삽입하며 정적 콘텐츠에는 `data-i18n`, `data-i18n-title`, `data-i18n-aria-label`, `data-i18n-placeholder`를 사용합니다. 템플릿 안의 메뉴 문구도 번역하고 같은 언어의 지역별 카탈로그를 함께 갱신하세요. 8개 README의 내용도 일치하도록 유지합니다. [Mozilla 국제화 안내](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Internationalization)를 참고하세요.
