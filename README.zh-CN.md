# FirefoxNewTab

一个轻量的 Firefox 新标签页扩展，提供网站快捷方式、分组、自定义背景和可选时钟。基于 Manifest V3，使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建，直接加载源文件即可使用。

## 功能

- 在网格中拖拽排列网站快捷方式，支持四种图标尺寸，并保存位置与空位。
- 通过可折叠的侧栏管理分组，支持跨分组拖动网站。
- 上传自定义图标，或按需直接从网站获取图标。
- 选择 7 张内置壁纸、本地图片或 48 种背景色。
- 选择黑色、白色或跟随系统主题，并按需显示本地时间和日期。
- 自动跟随 Firefox 显示语言，动效遵循系统的“减少动态效果”偏好。

## 在 Firefox 中加载

按需获取网站图标依赖 [`optional_host_permissions`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_host_permissions)，使用此功能需 Firefox 128 或更高版本。

1. 下载或克隆本仓库，保持项目文件结构完整。
2. 在 Firefox 中打开 `about:debugging#/runtime/this-firefox`。
3. 点击“临时载入附加组件…”，选择项目根目录中的 `manifest.json`。
4. 如果出现提示，允许扩展接管新标签页。
5. 打开新标签页，在背景空白处右键添加第一个网站，或点击右下角齿轮打开设置。

临时安装在 Firefox 重启后失效，之后需要重新加载。参见 [Mozilla 临时安装说明](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)。

## 网站快捷方式

### 添加和管理网站

首次使用时网站列表为空。在背景空白处右键，可使用以下操作：

| 操作 | 作用 |
| --- | --- |
| 添加图标 | 在当前分组中添加网站。 |
| 换壁纸 | 打开设置并定位到内置壁纸区域。 |
| 设置 | 打开设置抽屉。 |

名称最多 50 个字符，网址仅支持 HTTP 和 HTTPS；省略协议时自动补上 `https://`。点击快捷方式会在当前标签页打开网站。

右键点击快捷方式，或使用右上角的三点按钮，可以打开、编辑、调整尺寸或删除网站。三点按钮在鼠标悬停或键盘聚焦时显示，触屏设备上始终显示。删除需要确认；取消编辑会放弃尚未保存的修改。

### 图标尺寸与网格容量

每个分组的桌面逻辑网格为 **10 列 × 6 行**，共 **60 个基础格**。

| 尺寸 | 列 × 行 | 占用格数 |
| --- | --- | --- |
| 正常 | 1 × 1 | 1 |
| 横图标 | 2 × 1 | 2 |
| 竖图标 | 1 × 2 | 2 |
| 大图标 | 2 × 2 | 4 |

一个分组最多容纳 60 个正常尺寸的快捷方式，较大图标还需要形状合适的连续空位。分组满额后禁用添加；新增、跨分组移动和调整尺寸时都会检查剩余空间。每个网站分别记住自己的尺寸。

拖动快捷方式，可放入空格，也可放在其他快捷方式上让其自动避让。位置和空位会保存。按 **Esc** 或取消拖动可恢复原布局；拖到滚动区域边缘可继续查看其他格子。

网格固定从侧栏右侧区域的左上方开始，仅在需要时滚动。窄窗口会减少列数，并为不同列数分别保存位置。窄屏拖动不会改写桌面位置，仅调整窗口大小也不会保存新位置。单列视图会暂时压缩横向跨度，空间充足时恢复原有宽度。

### 分组

侧栏默认提供“常用”分组。点击“添加分组”可创建更多分组，名称最多 20 个字符。分组设置中可以修改名称，并使用文字、表情或本地图片作为图标。

将网站拖到某个分组上即可移入；侧栏折叠时也可以拖到分组图标上。目标分组空间不足时，网站保留在原位置。

点击侧栏顶部的箭头可收起或展开侧栏，当前分组和折叠状态会保存。所有分组都可改名或删除，包括最初的分组，但至少需要保留一个。删除分组后，其中的网站和图标会移入首个剩余分组。

切换分组时根据侧栏顺序播放上下滑动动画；调整图标尺寸和展开、收起侧栏时也有平滑过渡。这些动效遵循系统的“减少动态效果”设置。

### 自定义和获取图标

- 网站和分组图标支持上传 PNG、JPEG、WebP、GIF、AVIF 或 ICO 文件，最大 **2 MiB**。
- 网站没有自定义图标时使用名称首字；点击“使用默认图标”可恢复这一效果。
- 图标保留原图比例，不放大，最长边最多 **512 px**，以约 **0.8** 的质量压缩为 WebP；必要时继续缩小，以满足 **128 KiB** 的图标存储数据上限。
- 已保存的 PNG 图标仍然兼容。旧版压缩至 128 px 的图标如需提高清晰度，需要重新上传原图或获取图标。

输入网站地址后点击“获取图标”，Firefox 会按需申请该网站的访问权限。扩展读取网站声明的图标，同时尝试 `/favicon.ico`，并将结果转换为本地预览；点击“保存”后才保留。获取失败或拒绝授权时会保留当前图标，仍可上传本地图片。不使用第三方图标服务。

## 外观与背景

点击右下角齿轮打开设置抽屉。点击关闭按钮、点击抽屉外部或按 **Esc** 均可关闭。

| 设置 | 选项与行为 |
| --- | --- |
| 主题 | “黑色”“白色”或“跟随系统”，默认跟随系统。 |
| 显示时钟 | 默认关闭。以 24 小时制 `HH:mm:ss` 显示本地时间和本地化日期，每秒刷新。 |
| 内置壁纸 | 提供 7 张图片，以两列展示；点击缩略图即可应用并保存。 |
| 本地背景图片 | 支持 PNG、JPEG、WebP、GIF 或 AVIF，最大 **10 MiB**；选择后自动应用并保存。 |
| 背景色 | 提供 48 种颜色；点击色块即可应用并保存。 |
| 默认背景 | 白色（`#ffffff`），首次使用或恢复默认时应用。 |

主题控制界面控件、菜单和弹窗的配色，保留已选择的壁纸或背景色。纯色背景较亮时，网站标题和时钟使用深色文字。主题、时钟显示与侧栏折叠偏好会同步到同一扩展已打开的其他新标签页。

## 界面语言

界面通过 [`browser.i18n.getUILanguage()`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/i18n/getUILanguage) 自动跟随 Firefox 的显示语言，没有单独的语言选择器。

支持简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语和葡萄牙语，其中葡萄牙语包含巴西与葡萄牙两个版本。地区语言使用对应或通用译文，未支持的语言回退到简体中文。修改 Firefox 显示语言后，重新打开新标签页即可。

菜单、设置、弹窗、提示、辅助标签、颜色名称、扩展名称、日期和默认分组名称均已本地化。用户填写的网站标题、网址和分组名称保持原文。时钟始终使用本地时区。

## 本地数据与权限

| 存储方式 | 内容 |
| --- | --- |
| `localStorage` | 网站、图标、网格位置、分组、当前分组、侧栏状态、主题和时钟显示偏好。 |
| `IndexedDB` | 背景选择和本地背景图片。 |

上传的图片保存在浏览器内。管理快捷方式和背景不需要额外权限；只有点击“获取图标”时才请求网站访问权限，拒绝后仍可上传本地图片。背景不使用外部图片服务。本地存储不可用时，管理操作会显示错误提示。

### 旧数据兼容

- 根据预置标记清理旧版默认网站，保留用户添加的网站和自定义图标。
- 旧版文件夹功能已移除，其中的网站会回到所属分组的主网格，保留名称、网址、图标和尺寸。
- 旧数据超过网格容量时，多余网站保留在“其余网站”列表，可打开、编辑或删除；腾出空间后会自动回到网格。

### 修改与重新加载

无需安装依赖或执行构建命令。修改源文件后，在 `about:debugging#/runtime/this-firefox` 中找到扩展并点击“重新载入”，关闭原有新标签页，再打开一个新标签页。

`newtab.html` 中的本地 CSS 和 JavaScript 引用使用统一的 `?v=...` 资源版本参数；修改这些资源时应一并更新。保持脚本依赖顺序：先加载 `i18n.js`，共用工具先于使用它们的模块，分组、网格、菜单、切换动画和数据迁移模块先于 `shortcuts.js`。各模块通过独立作用域保存内部状态，通过明确接口或事件协作。图标处理与容量规则各保留一份实现；壁纸选择器样式仅作用于设置抽屉。

### 更新翻译

`_locales/*/messages.json` 使用一致的消息键，通过 `newTabI18n.t(key, { name, count })` 插入命名参数。静态内容使用 `data-i18n`、`data-i18n-title`、`data-i18n-aria-label` 和 `data-i18n-placeholder`。同时处理模板内的菜单文字，一并更新对应地区的消息目录，并保持 8 种 README 内容一致。参见 [Mozilla 扩展国际化说明](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Internationalization)。
