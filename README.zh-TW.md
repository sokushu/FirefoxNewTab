# FirefoxNewTab

一個輕量的 Firefox 新分頁擴充套件，提供網站捷徑、分組、自訂背景和可選時鐘。以 Manifest V3 為基礎，使用原生 HTML、CSS 和 JavaScript，無須安裝相依套件或建置，直接載入原始檔即可使用。

## 功能

- 在網格中拖曳排列網站捷徑，支援四種圖示尺寸，並儲存位置與空格。
- 透過可收合的側邊欄管理分組，支援跨分組拖動網站。
- 上傳自訂圖示，或視需要直接從網站取得圖示。
- 選擇 7 張內建桌布、本機圖片或 48 種背景色。
- 選擇深色、淺色或跟隨系統佈景主題，並視需要顯示本地時間和日期。
- 自動跟隨 Firefox 顯示語言，動畫遵循系統的「減少動態效果」偏好。

## 在 Firefox 中載入

按需取得網站圖示依賴 [`optional_host_permissions`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_host_permissions)，使用此功能需 Firefox 128 或更新版本。

1. 下載或複製本儲存庫，保持專案檔案結構完整。
2. 在 Firefox 中開啟 `about:debugging#/runtime/this-firefox`。
3. 點選「暫時載入附加元件…」，選擇專案根目錄中的 `manifest.json`。
4. 若出現提示，允許擴充套件取代新分頁。
5. 開啟新分頁，在背景空白處按右鍵新增第一個網站，或點選右下角齒輪開啟設定。

暫時安裝在 Firefox 重新啟動後失效，之後需要重新載入。請參閱 [Mozilla 暫時安裝說明](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)。

## 網站捷徑

### 新增和管理網站

首次使用時網站清單為空。在背景空白處按右鍵，可使用以下操作：

| 操作 | 用途 |
| --- | --- |
| 新增圖示 | 在目前分組中新增網站。 |
| 更換桌布 | 開啟設定並移至內建桌布區域。 |
| 設定 | 開啟設定抽屜。 |

名稱最多 50 個字元，網址僅支援 HTTP 和 HTTPS；省略通訊協定時會自動補上 `https://`。點選捷徑會在目前分頁開啟網站。

在捷徑上按右鍵，或使用右上角的三點按鈕，可以開啟、編輯、調整尺寸或刪除網站。三點按鈕在滑鼠停留或鍵盤聚焦時顯示，觸控裝置上則持續顯示。刪除需要確認；取消編輯會捨棄尚未儲存的變更。

### 圖示尺寸與網格容量

每個分組的桌面邏輯網格為 **10 欄 × 6 列**，共 **60 個基本格**。

| 尺寸 | 欄 × 列 | 使用格數 |
| --- | --- | --- |
| 一般 | 1 × 1 | 1 |
| 橫向圖示 | 2 × 1 | 2 |
| 直向圖示 | 1 × 2 | 2 |
| 大型圖示 | 2 × 2 | 4 |

一個分組最多容納 60 個一般尺寸的捷徑，較大圖示還需要形狀合適的連續空格。分組滿額後停用新增；新增、跨分組移動和調整尺寸時，都會檢查剩餘空間。每個網站分別記住自己的尺寸。

拖動捷徑可放入空格，也可放在其他捷徑上，讓其自動移開。位置和空格會儲存。按 **Esc** 或取消拖動可還原原始配置；拖到捲動區域邊緣可繼續查看其他格子。

網格固定從側邊欄右側區域的左上方開始，僅在需要時捲動。窄視窗會減少欄數，並為不同欄數分別儲存位置。窄螢幕拖動不會覆寫桌面位置，僅調整視窗大小也不會儲存新位置。單欄檢視會暫時壓縮橫向跨度，空間充足時恢復原有寬度。

### 分組

側邊欄預設提供「常用」分組。點選「新增分組」可建立更多分組，名稱最多 20 個字元。分組設定中可以修改名稱，並使用文字、表情符號或本機圖片作為圖示。

將網站拖到某個分組上即可移入；側邊欄收合時也可以拖到分組圖示上。目標分組空間不足時，網站會保留在原位置。

點選側邊欄頂端的箭頭可收合或展開側邊欄，目前分組和收合狀態會儲存。所有分組都可重新命名或刪除，包括最初的分組，但至少需要保留一個。刪除分組後，其中的網站和圖示會移入第一個剩餘分組。

切換分組時，會根據側邊欄順序播放上下滑動動畫；調整圖示尺寸和收合、展開側邊欄時也有平滑轉場。這些動畫遵循系統的「減少動態效果」設定。

### 自訂和取得圖示

- 網站和分組圖示支援上傳 PNG、JPEG、WebP、GIF、AVIF 或 ICO 檔案，最大 **2 MiB**。
- 網站沒有自訂圖示時使用名稱首字；點選「使用預設圖示」可恢復此效果。
- 圖示保留原圖比例，不放大，最長邊最多 **512 px**，以約 **0.8** 的品質壓縮為 WebP；必要時繼續縮小，以符合 **128 KiB** 的圖示儲存資料上限。
- 已儲存的 PNG 圖示仍然相容。舊版壓縮至 128 px 的圖示若需提高清晰度，必須重新上傳原圖或取得圖示。

輸入網站地址後點選「取得圖示」，Firefox 會視需要要求該網站的存取權限。擴充套件讀取網站宣告的圖示，同時嘗試 `/favicon.ico`，並將結果轉換為本機預覽；點選「儲存」後才保留。取得失敗或拒絕授權時會保留目前圖示，仍可上傳本機圖片。不使用第三方圖示服務。

## 外觀與背景

點選右下角齒輪開啟設定抽屜。點選關閉按鈕、點選抽屜外部或按 **Esc** 均可關閉。

| 設定 | 選項與行為 |
| --- | --- |
| 佈景主題 | 「深色」「淺色」或「跟隨系統」，預設跟隨系統。 |
| 顯示時鐘 | 預設關閉。以 24 小時制 `HH:mm:ss` 顯示本地時間和本地化日期，每秒更新。 |
| 內建桌布 | 提供 7 張圖片，以兩欄顯示；點選縮圖即可套用並儲存。 |
| 本機背景圖片 | 支援 PNG、JPEG、WebP、GIF 或 AVIF，最大 **10 MiB**；選擇後自動套用並儲存。 |
| 背景色 | 提供 48 種顏色；點選色塊即可套用並儲存。 |
| 預設背景 | 白色（`#ffffff`），首次使用或還原預設時套用。 |

佈景主題控制介面控制項、選單和對話框的配色，保留已選擇的桌布或背景色。純色背景較亮時，網站標題和時鐘使用深色文字。佈景主題、時鐘顯示與側邊欄收合偏好會同步至同一擴充套件已開啟的其他新分頁。

## 介面語言

介面透過 [`browser.i18n.getUILanguage()`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/i18n/getUILanguage) 自動跟隨 Firefox 的顯示語言，沒有獨立的語言選擇器。

支援簡體中文、繁體中文、英語、日語、韓語、西班牙語、法語、德語和葡萄牙語，其中葡萄牙語包含巴西與葡萄牙兩個版本。地區語言使用對應或通用譯文，未支援的語言會回退至簡體中文。修改 Firefox 顯示語言後，重新開啟新分頁即可。

選單、設定、對話框、提示、無障礙標籤、顏色名稱、擴充套件名稱、日期和預設分組名稱均已本地化。使用者輸入的網站標題、網址和分組名稱保持原文。時鐘一律使用本地時區。

## 本機資料與權限

| 儲存方式 | 內容 |
| --- | --- |
| `localStorage` | 網站、圖示、網格位置、分組、目前分組、側邊欄狀態、佈景主題和時鐘顯示偏好。 |
| `IndexedDB` | 背景選擇和本機背景圖片。 |

上傳的圖片儲存在瀏覽器內。管理捷徑和背景無須額外權限；只有點選「取得圖示」時才要求網站存取權限，拒絕後仍可上傳本機圖片。背景不使用外部圖片服務。本機儲存空間無法使用時，管理操作會顯示錯誤提示。

### 舊資料相容性

- 根據預設標記清理舊版預設網站，保留使用者新增的網站和自訂圖示。
- 舊版資料夾功能已移除，其中的網站會回到所屬分組的主網格，保留名稱、網址、圖示和尺寸。
- 舊資料超過網格容量時，多餘網站保留在「其餘網站」清單，可開啟、編輯或刪除；騰出空間後會自動回到網格。

### 修改與重新載入

無須安裝相依套件或執行建置命令。修改原始檔後，在 `about:debugging#/runtime/this-firefox` 中找到擴充套件並點選「重新載入」，關閉原有新分頁，再開啟一個新分頁。

`newtab.html` 中的本機 CSS 和 JavaScript 引用使用統一的 `?v=...` 資源版本參數；修改這些資源時應一併更新。保持指令碼相依順序：先載入 `i18n.js`，共用工具先於使用它們的模組，分組、網格、選單、轉場動畫和資料遷移模組先於 `shortcuts.js`。各模組在獨立作用域中儲存內部狀態，透過明確介面或事件協作。圖示處理與容量規則各保留一份實作；桌布選擇器樣式僅作用於設定抽屜。

### 更新翻譯

`_locales/*/messages.json` 使用一致的訊息鍵，透過 `newTabI18n.t(key, { name, count })` 插入具名參數。靜態內容使用 `data-i18n`、`data-i18n-title`、`data-i18n-aria-label` 和 `data-i18n-placeholder`。同時處理範本內的選單文字，一併更新對應地區的訊息目錄，並保持 8 種 README 內容一致。請參閱 [Mozilla 擴充套件國際化說明](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Internationalization)。
